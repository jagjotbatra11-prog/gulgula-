FREE LOVE WEBSITE — GULGULA + SIRJI 🩷

Included: index.html, style.css, script.js.
No paid subscription, login, tracking, or private-link service is required.

PUBLISH FREE WITH GITHUB PAGES (phone-friendly):
1. Download/unzip this folder.
2. Sign in or create a free account at https://github.com
3. Create a NEW public repository named: sirji-love-site
4. Choose Add file > Upload files, and upload index.html, style.css, script.js (not the zip).
5. Tap Commit changes.
6. Open repository Settings > Pages.
7. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
8. Wait a minute or two. The public site address will appear on the Pages settings screen.

PERSONALIZE:
Edit index.html to change Sirji, Gulgula, and the letter text. You can do this using GitHub's pencil/Edit button on each file.
To change colors, edit the hex color values near the top of style.css.
The design is an original free recreation inspired by the screen recording, not an exact copy of the paid site's proprietary template/artwork. Avoid uploading private photos or sensitive details to a public repository.
